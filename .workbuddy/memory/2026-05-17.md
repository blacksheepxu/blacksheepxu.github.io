## GitHub Actions CI 修复

- **问题**：CI 构建失败，报 `Missing site/about content entry` + `The collection "posts" does not exist`
- **根因**：dependabot PR 将 astro 升到 v6（依赖 zod v4），但项目 content schema 基于 zod v3 编写（使用了 `superRefine`、`z.ZodIssueCode.custom` 等），zod v3/v4 不兼容导致 `zod-to-json-schema` 调用 `Cannot read properties of undefined (reading 'def')`
- **修复**：
  1. `package.json` 锁定 `astro: ^5.0.0`、`@astrojs/mdx: ^4.0.0`
  2. CI workflow 改用 `npm ci` 替代 `npm install`，防止版本漂移
  3. Node 版本升级为 22（之前一轮已做）
  4. 重新生成 `package-lock.json`
- **PR**：#14 (https://github.com/blacksheepxu/blacksheepxu.github.io/pull/14)
- **教训**：astro v5→v6 是 zod v3→v4 的破坏性升级，dependabot 不会感知这类语义不兼容
